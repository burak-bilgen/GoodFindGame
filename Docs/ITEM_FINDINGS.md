# Persistent category findings

Master brief sections 14–16 call for different evidence in each category. Item instances now carry optional versioned `ItemFacts` and a persisted set of revealed field keys. Facts are generated once using an independent item/definition seed, never when a screen redraws or an inspection starts. They travel unchanged through purchase, shipment and resale snapshots.

Camera bodies record shutter count and battery health. Body/lens classification follows the definition's body-specific defect pool. The four lens definitions never receive shutter, battery or sensor measurements. Applicable models also record optical, sensor, autofocus, aperture and stabilization test results. Counts/health and test outcomes agree with the item's already-generated faults; inspection does not create damage. Worn shutters have 120,000–240,000 actuations; other bodies have 1,000–85,000. Worn batteries measure 35–65%, others 75–100%. These are initial fictional simulation ranges, not real product specifications.

Retro findings cover Region A/B/region-free compatibility, missing manuals/components (including both), original/worn packaging, replacement parts, authenticity and edition. The fictional local market uses Region A. Reproduction boards are distinguishable from replacement parts. All current items are standard editions; this does not implement the later rare-variant content target. Cosmetic score reuses the instance's existing visible condition; it does not add a new random economic factor.

A free check reveals cosmetic and obvious completeness/packaging/edition evidence. Battery health and parts testing require rank one plus the category kit; shutter count, autofocus and region require rank two plus the kit; full optical/sensor/aperture/stabilization/authenticity tests require rank three plus the kit. Professional reports reveal all recorded fields at actual persisted completion. Locked fields never show a healthy/default result. Facts conclusively establishing a fault also reveal that fault for the defect summary and estimated value; they supplement the existing bounded diagnostic fault pass. This prevents a missing-pieces report from coexisting with a clean estimate.

Attributes explain the existing condition/defect valuation and do not add another bonus/penalty for the same issue. There is no unseen-defect-based deal rating or new pricing random draw. Buying tools alone reveals nothing, and capability rechecks still award no repeat experience.

Existing saves decode absent optional fields. Old items retain their exact condition, hidden/revealed defects and financial facts; no historic shutter count, battery measurement or authenticity test is invented. Their findings screen explains the missing record. New stock receives measurements. Save loading validates schema version, category-specific field membership, uniqueness, value type/range and revealed-key membership across market, inventory, shipments and resale snapshots.

The localized findings screen is reached from an owned item. Native verification covers camera and retro purchase → self-check with locked advanced field → expert completion → actual field value → relaunch with the same value, in both languages. Numerical/category findings, tool/rank limits, old-item compatibility, exact original starter price, unchanged valuation and invalid-save rejection also have domain tests. Final evidence is recorded in STATUS.md.

Timed repairs, rare editions/collections, broader progression, human economy validation and the final game interface/art remain required work.
