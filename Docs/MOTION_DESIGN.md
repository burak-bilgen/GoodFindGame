# Motion and coordinated feedback

Use native SwiftUI/Core Animation and the existing short original synthesized audio queue. No Lottie/Rive dependency: all required effects are state/card/numeric transitions or small finite shapes; no externally authored character animation currently justifies runtime/license/startup cost.

| Meaning | Motion | Audio/haptic | Rule |
| --- | --- | --- | --- |
| Submit | Button press + pending activity lights | Light tap, short tone | Immediate input acknowledgement, not acceptance |
| Seller acceptance / purchase | Incoming reply/card and confirmation seal | Existing ascending confirmation + success | Actual saved result only |
| Waiting | Low-frequency radar or activity lights | Silent | No invented percentage or reward |
| Inspection | Three finite evidence stages; photo comparison crossfade | Reveal then warning for earned defect | Skippable; report memory suppresses repeated reveal |
| Price/cash change | Numeric text transition | No continual sound | Actual values only, no fake countup proceeds |
| Trade result | Object hero, finite seal, existing localized payoff particles | Existing profit/loss cue on settlement | Loss uses warning, not celebration; receipt revisits don't grant rewards |
| Career/client/display later | Finite state transition and milestone acknowledgement | Success cue on explicit completed action | No reward shower or repeated sound on reopening |

Reduce Motion removes movement/particles and uses immediate states/opacity. VoiceOver receives complete inspection evidence without waiting. Decorative animation pauses in background. Buttons never move away from an incoming tap. Sound remains opt-in and respects silent mode; haptic fidelity and real audio still need physical-device review. Large text preserves reading order and minimum touch targets.

The hunt header now treats cash as a compact instrument in the marketplace world and keeps product cards prominent. Profile uses a trader portrait. Trade outcomes include the actual object so the payoff records a specific decision, not only a financial total.
