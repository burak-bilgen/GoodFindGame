# Project Flip trading

The player trades fictional second-hand goods under incomplete information. English and Turkish terms describe the same economic concepts.

## Language

**Asking price / İlan fiyatı**:
The amount a seller requests in a listing; it can differ from market value.
_Avoid_: Fair price, gerçek değer

**Market value / Piyasa değeri**:
The prevailing value of an item given its actual condition and current demand.
_Avoid_: Guaranteed sale price, kesin satış fiyatı

**Estimated value / Tahmini değer**:
The player's imperfect assessment of value using currently available information.
_Avoid_: Market value when only an estimate is known

**Inspection / İnceleme**:
An examination that reveals some or all of an item's condition.

**Hidden defect / Gizli kusur**:
An existing problem that has not yet been revealed to the player.
_Avoid_: Random damage generated during inspection

**Repair / Onarım**:
Work intended to correct a defect, with a cost and a possible change in value.

**Offer / Teklif**:
A proposed purchase or sale amount that the other participant can accept, reject or counter.

**Counteroffer / Karşı teklif**:
A new price proposed in response to an existing offer.

**Reputation / İtibar**:
The trust a trader has earned through their marketplace behavior.

**Collection / Koleksiyon**:
A themed set of items retained for completion and prestige.

**Market trend / Piyasa eğilimi**:
A bounded change in demand or value over time.

**Realized profit / Gerçekleşen kâr**:
Completed sale proceeds minus acquisition, inspection and repair costs. A negative result is a realized loss / gerçekleşen zarar.
_Avoid_: Cash balance, unrealized inventory appreciation
